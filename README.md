# DC Felony Sentencing Analysis

## Overview
This project analyzes felony sentencing data in Washington D.C. using the full data science pipeline, including:

- Data preprocessing and cleaning
- Exploratory data analysis
- Hypothesis testing
- Machine learning modeling
- Visualization and interpretation

The goal of this project is to investigate which factors most strongly influence sentencing outcomes and whether demographic variables may play a role in sentencing patterns.

## Key Findings
- Offense type and offense severity were the strongest predictors of sentencing length.
- Models achieved R² values between 0.79 and 0.81 for sentence prediction.
- Demographic variables still explained part of sentencing variance.
- Serve ratio prediction achieved very high accuracy (R² = 0.97).
